# GoMoneyAdmin

## UAT 網址

https://uat-payment-admin.mxsyl.com/zh-CN/login


## 測試帳號

放在 `.env`，都是 UAT 帳號，變數名稱見 `.env` 裡的 GoMoneyAdmin 區塊。

## 主要模組

左側選單：会员管理、财务管理、钱包管理、支付管理、财务钱包、风控管理、报表、权限管理、系统管理。

登入後預設進入「会员管理 > 会员列表」。

## 注意事項

- 登入頁標題是「GoMoney 系统登录」，表單只有帳號、密碼兩欄，沒有圖形驗證碼。
- 帳密通過後會要求 OTP 驗證碼，寄到帳號綁定的工作信箱。沒收到的話，約一分鐘後才能重新寄送。
- UAT 有固定的 OTP 測試碼，存在 `.env` 的 `OTP_CODE`，所有後台共用。驗證碼頁只有一個輸入框，填入後按確認即可登入。
