# ALL-15193 測試案例（定案版）

- 定案日期：2026-11-06
- 討論文件：https://claude.ai/artifact/9iwdfAvAisyo7ajM7561To
- 測試環境：PlatformWeb m8 的 UAT，https://uat8-newplatform.mxsyl.com/zh-cn
- 測試帳號：`.env` 的 PlatformWeb 玩家帳號
- TestRail 測試執行：R556，https://gorun.testrail.io/index.php?/runs/view/556
- 判斷依據：從網頁收到的後端資料讀出每個幣別與網路的原始最低儲值（`minDeposit`），依下表無條件進位後，必須等於畫面顯示的金額。

| 幣別 | 進位到小數幾位 |
| --- | --- |
| 穩定幣（USDT、USDC 等） | 2 |
| BTC、ETH | 8 |
| 其他 | 6 |

共通前置條件：已用玩家帳號登入 m8 前台，帳號可以打開存款視窗。
